# 영상 퀴즈 도우미

영상(화면 녹화 파일 또는 유튜브 링크)을 넣으면 소리를 글로 바꿔 저장하고,
퀴즈 문제를 붙여넣으면 **영상 속 내용을 근거로** 정답과 해당 시각·인용문을 보여줘요.

```
영상 → (ffmpeg) 소리 추출 → (Whisper) 글로 변환 → 저장
문제 붙여넣기 → (Claude) 저장된 스크립트에서 근거 찾기 → 정답 + 근거 시각
```

## 준비물 (처음 한 번만)

1. **Python 3.10 이상** — https://www.python.org/downloads/ (Windows는 설치할 때 "Add Python to PATH" 체크)
2. **ffmpeg** — 영상에서 소리를 꺼내는 도구
   - Windows: 터미널(PowerShell)에서 `winget install ffmpeg`
   - Mac: `brew install ffmpeg`
3. **Anthropic API 키** — https://console.anthropic.com 에서 발급 (사용한 만큼 과금돼요)

## 설치

이 폴더에서 터미널을 열고:

```bash
pip install -r requirements.txt
```

그다음 `.env.example` 파일을 복사해서 이름을 `.env` 로 바꾸고, 안에 API 키를 붙여넣어요.

## 실행

```bash
python app.py
```

브라우저가 자동으로 열려요. (안 열리면 http://127.0.0.1:8765 로 접속)
끌 때는 터미널에서 `Ctrl + C`.

## 사용법

1. **영상 넣기** — 녹화 파일을 끌어다 놓거나, 유튜브 주소를 붙여넣고 `영상 분석 시작`.
2. **영상 고르기** — 목록에서 근거로 쓸 영상을 체크. 한 번 분석한 영상은 저장되어 있어서 다시 분석할 필요 없어요.
3. **문제 붙여넣기** — 문제와 보기를 그대로 붙여넣고 `정답 찾기`. 여러 문제를 한꺼번에 붙여넣어도 돼요.

결과에는 정답 외에 아래가 같이 나와요.
- **근거 시각과 인용** — 영상의 몇 분 몇 초에서 나온 말인지
- **출처 표시** — 영상에 직접 나옴 / 영상에서 추론 / 영상에서 근거를 못 찾음(이때는 일반 지식으로 추정한 것이라고 따로 표시)
- **확신도** — 낮음이면 해당 시각을 직접 확인해 보세요

## 친구에게 공유하기 (1회용 · 시간 제한)

**영상은 내가 올리고, 친구는 질문만 해요.** 친구는 영상을 올릴 수 없고, 내가 골라서 공유한 영상에 대해서만 문제를 붙여넣어 정답을 받아요.

- 화면 맨 아래 **친구 초대**에서 `1회용 링크`를 만들어 보내요. 만들 때 **친구가 쓸 영상을 직접 체크**해요 (체크하지 않은 영상은 제목도 안 보여요).
- 링크는 **한 번만** 열 수 있어요. 친구가 열고 `시작하기`를 누른 순간부터 정한 시간(30분~24시간) 동안만 쓸 수 있고, 끝나면 더 이상 쓸 수 없어요.
- 친구마다 **질문 횟수**를 정할 수 있어요. 친구가 질문할 때마다 **내 API 비용**이 나가기 때문이에요.
- 친구가 할 수 있는 건 "공유된 영상 보기"와 "문제 붙여넣고 정답 받기"뿐이에요. 영상 올리기·삭제, 스크립트 보기, 내 API 키, 초대 관리는 모두 막혀 있어요.
- 카카오톡 같은 곳에 링크를 보내도 미리보기가 링크를 대신 열어서 소모되지 않아요 (`시작하기` 버튼을 눌러야 시작).
- 링크를 만들고 24시간 안에 안 열면 저절로 못 쓰게 돼요. 초대 목록에서 언제든 `취소`할 수 있어요.

### 켜는 방법

내 컴퓨터는 기본적으로 나만 접속할 수 있어서, 친구가 들어올 **임시 공개 주소**가 필요해요. 무료 `cloudflared` 터널을 쓰면 가입 없이 돼요.

1. **cloudflared 설치** (처음 한 번)
   - Windows: `winget install Cloudflare.cloudflared`
   - Mac: `brew install cloudflared`
2. 앱을 이렇게 켜요.
   ```bash
   python app.py --share
   ```
   터미널에 `https://....trycloudflare.com` 주소가 나오고, 화면 맨 아래 **친구 초대**에 자동으로 채워져요.
3. 먼저 내 영상을 올려 두고, **친구 이름 / 이용 시간 / 질문 횟수**를 정하고 공유할 영상을 체크한 뒤 `1회용 링크 만들기` → 나온 안내 문구를 `복사하기`로 친구에게 보내세요.

> ngrok 같은 다른 터널을 쓴다면 앱을 평소처럼 켜고, 터널 주소를 **친구 초대**의 '공개 주소' 칸에 붙여넣으면 돼요.

### 알아둘 점 (공유할 때)

- **내 컴퓨터와 앱이 켜져 있는 동안만** 친구가 쓸 수 있어요. 터미널 창을 닫으면 공유도 끝나고, 다음에 `--share`로 켜면 주소가 새로 바뀌어요.
- 친구가 붙여넣은 문제와 공유한 영상의 스크립트는 정답을 찾으려고 **Claude API로 전송**돼요. 친구에게 미리 알려 주면 좋아요 (친구 화면에도 안내가 나와요).
- 정답에 붙는 **근거 인용문**에는 공유한 영상 속 말이 일부 들어가요. 공유하고 싶지 않은 영상은 체크하지 마세요.
- 공유한 영상을 내가 지우면 친구 목록에서도 바로 사라져요.
- 이 앱은 짧게 쓰고 끄는 용도로 만들었어요. 공유 주소를 오래 켜두거나 많은 사람에게 퍼뜨리는 건 권하지 않아요.

## 알아둘 점

- **처음 영상을 분석할 때** 음성 인식 모델을 내려받아서 오래 걸려요 (small 모델 약 500MB). 이후엔 빨라요.
- **유튜브 링크**는 자막이 있으면 자막을 바로 가져와서 몇 초 만에 끝나요. 자막이 없으면 오디오를 내려받아 음성 인식을 해요.
- **음성 인식은 완벽하지 않아요.** 사람 이름, 성경 구절, 숫자가 틀리게 들릴 수 있어요. 정확도가 아쉬우면 `.env`에 `WHISPER_MODEL=medium` 을 추가해 보세요 (더 느려져요).
- 영상 길이만큼 걸린다고 생각하면 편해요. CPU 기준으로 `small` 모델은 영상 길이의 절반~1배 정도, GPU가 있으면 훨씬 빨라요.
- 분석한 스크립트는 `data/videos/` 폴더에 저장돼요. 영상 파일 자체는 저장하지 않고, 분석이 끝나면 임시 파일을 지워요.
- 문제 풀이를 위해 **스크립트 글과 문제 텍스트가 Claude API로 전송**돼요. 영상 파일은 내 컴퓨터를 벗어나지 않아요.
- 정답은 참고용이에요. 확신도가 낮거나 "영상에서 근거를 못 찾음"으로 나오면 꼭 직접 확인하세요.

## 문제가 생기면

| 증상 | 해결 |
|---|---|
| 화면 위에 빨간 경고가 떠요 | 경고 문구대로 API 키/ffmpeg 설정 |
| `pip` 명령을 못 찾아요 | `python -m pip install -r requirements.txt` |
| 유튜브 분석이 실패해요 | `pip install -U yt-dlp` 로 업데이트 (유튜브가 바뀌면 자주 필요해요) |
| 음성 인식 결과가 이상해요 | 영상 언어를 직접 선택, 또는 `WHISPER_MODEL=medium` |
| 정답이 자꾸 "근거 없음"으로 나와요 | 스크립트 보기로 소리가 제대로 글로 바뀌었는지 확인 |
