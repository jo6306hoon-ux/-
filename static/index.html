영상 퀴즈 도우미

영상을 넣고 문제를 붙여넣으면, 영상 속 내용을 근거로 정답을 찾아줘요.

1. 영상 넣기

영상 파일을 여기로 끌어다 놓거나 눌러서 선택
mp4, mov, mkv, webm, m4a, mp3 등

2. 근거로 쓸 영상 고르기

아직 넣은 영상이 없어요.

3. 문제 붙여넣기

Ctrl + Enter (Mac은 ⌘ + Enter)로도 실행돼요.

친구 초대 1회용 · 시간 제한

친구에게 1회용 링크를 보내면, 친구가 링크를 열고 시작하기를 누른 순간부터 정한 시간 동안만 쓸 수 있어요. 친구는 영상을 올릴 수 없고, 아래에서 고른 영상에 대해서만 문제를 붙여넣어 정답을 받아요. 친구가 질문할 때마다 내 API 비용이 드니 횟수를 제한해 두세요. 이 앱이 켜져 있는 동안만 친구가 쓸 수 있어요.
